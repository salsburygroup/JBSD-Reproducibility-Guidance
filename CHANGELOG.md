# Changelog

## 0.1.2 — 2026-08-26

- Replaced the trained-ML example with a conventional GROMACS molecular-dynamics Methods example.
- Removed the reproducibility-boundary section from the Methods example.
- Removed YAML-based files and the pooling-group column from the simulation-deposit example.

## 0.1.1 — 2026-08-26

- Made pooled-replica analysis the default for conventional and coarse-grained molecular dynamics.
- Removed routine convergence tests, uncertainty estimates, and between-replica comparisons from the MD guidance.
- Kept convergence and uncertainty reporting specific to enhanced-sampling and free-energy methods.
- Updated the simulation-deposit example to use pooled outputs.

## 0.1.0 — 2026-08-26

- Added a universal computational checklist.
- Added method-specific checklists for molecular dynamics, enhanced sampling and free energy, coarse-grained models, QM/DFT, trained ML and machine-learned potentials, non-structure-based models, blots and gels, and AI-assisted research.
- Added deposit, manuscript-mapping, Data Availability Statement, generative-AI declaration, and exception-request templates.
- Added fictional examples of a simulation deposit and a computational Methods section.
- Stated that the checklists add no requirements and need not be submitted.
